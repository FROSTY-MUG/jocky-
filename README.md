# JOCKY: Resilient Digital Forensics & Incident Response (DFIR) Platform

JOCKY is a consent-bound, attested, domain-specific digital forensics and incident response platform designed to maintain forensic continuity on endpoints where security tools may be degraded or blinded by adversaries.

## Safety & Ethics Policy
All execution requires a valid cryptographically signed consent token. No off-target operations, unauthorized scanning, cross-process injection, or driver exploitation are permitted.
