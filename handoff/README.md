# JOCKY — Handoff

**Read this file first.** It is the entry point for any agent or human resuming work on this repository.

## What this is

JOCKY is a consent-bound Digital Forensics & Incident Response (DFIR) platform for SIH26148 (NTRO). It comprises a custom domain-specific language, an LLVM-based compiler, a signed module format (.jkm), and a distributed agent/manager architecture. All capabilities are defensive and authorized-use only.
